# 离线换版冻结与回读续作 v2

在保留 v1（`pixel-type --source … --output …` 的输入、报告、SVG、退出行为）的前提下，新增两个离线子命令；全程不接真实设备，不发送任何写入。

## 命令

```
pixel-type seal --store DIR --release-id ID --request-sha256 SHA --source FILE
pixel-type reconcile --store DIR --release-id ID --request-sha256 SHA --readback FILE --output REPORT
```

`release-id`、`panel_id`、窗口 `id` 均为 1–64 个 ASCII 字母、数字、下划线或连字符。`request-sha256` 为源文件原始字节的 64 位小写十六进制 SHA-256。

## 换版源文件与屏幕口径

源 JSON 字段：`panel_id`、`width`、`height`、`max_tiles_per_write`、`old`、`new`、`protected_windows`。

- 屏宽、高是 8 的正整数倍，至多 256×128。屏幕以左上角为原点，按 8×8 分块，块坐标 `(tx,ty)` 从 0 起。
- `max_tiles_per_write` 为 1 到屏内块数的整数；单条设备命令最多原子写入该数量的块，块可以不相邻。
- `old`、`new` 各自是完整 v1 排版输入，独立通过 v1 校验。屏上实际墨点直接由现有字偶、换行、offset 管道渲染得到；同一点重复绘制只亮一个灯，空白字形（空 `rows`）不点灯。
- 实际墨点越出物理屏直接拒绝冻结，不裁切；仅名义行溢出而实际墨点仍在屏内则不拒绝，仍可冻结。
- `protected_windows` 为 0–128 条带唯一 `id` 的半开像素矩形 `[x0,y0,x1,y1)`，非空且在屏内，允许跨块、重叠。

## 不可拆写入组

对某个保护窗口，旧屏与新屏在窗口内**实际翻转像素**所在的变化块，必须在同一次原子写入中切换。判定口径：

- 块仅与窗口相交、但翻点不在窗口内，不产生联结；
- 旧、新都亮的重叠墨点不是翻转，不参与联结；
- 同一块被多个窗口要求时，所有约束同时生效（并查集求传递闭包）。

交付最小不可拆组：每个变化块恰好属于一组；可独立前进的组不捆在一起；未变化的块不写入。任一组块数超过 `max_tiles_per_write` 则拒绝冻结整个改版，诊断列出超限组的块坐标与参与约束的窗口 ID，不拆成多个不安全的包。整屏无变化可以冻结，方案写入组为空。

## 冻结与重取

`seal` 先校验源存在、字节摘要与参数一致，完成全部校验后才使发布可见。成功向 stdout 输出自包含 JSON 方案，含发布/面板/摘要/设备规格、每组旧新两种块位图与核对条件、整屏旧新块位图以及保护窗口与其影响块。

存储目录内发布 ID 一旦冻结不可改绑：

- 相同 ID、相同摘要重试，返回已冻结方案的**完全相同字节**，优先于读取当前源文件；首次成功后源文件被替换或删除仍可重取；
- 相同 ID、不同摘要报冲突，不覆盖原发布；
- 方案文件先写临时名并 `fsync`，再原子替换，最后提交索引并 `fsync` 目录；目录锁（`flock`）串行化并发冻结，保证同 ID 并发只有一方成功，不存在双赢、半条可用记录或返回其他请求的方案；
- 进程在冻结边界中断后，重启仅能看到尚未冻结或完整可重取的发布（临时文件与无索引的孤儿方案在下次进入存储时清扫）。仅要求覆盖进程中断，不要求模拟机器掉电。

## 回读续作

`reconcile` 只使用该身份对应的冻结方案，不从源文件重新推导，也不改变冻结状态。

回读 JSON 含 `panel_id` 与 `tiles`；块记录为 `tx,ty,rows`，`rows` 为自上而下 8 行、每行从左到右 8 位 01 串。允许只读回部分块；面板不符、重复块、越界坐标或坏位图退出 2。未回读的块不是全暗，按缺读处理。

每组的核对范围 = 该组全部变化块的**整块** ∪ 所有要求该组联合切换窗口的**整个矩形**（含落在不写块上的旧新不变像素）。范围内逐像素与冻结旧屏、新屏比较：

| 条件 | 状态 |
| --- | --- |
| 旧、新两种解释都被已知像素排除（含组内一部分呈旧、一部分呈新且无共同解释，或应不变像素漂移），即使另有缺读 | `conflict` |
| 至少一种解释未排除，但核对范围有缺读 | `unconfirmed` |
| 无缺读且完整符合旧屏 | `ready` |
| 无缺读且完整符合新屏 | `applied` |

仅 `ready` 组附 `next_write`：下一条完整原子写入的块坐标、目标（新）位图，以及执行方可核对的旧态前置像素条件；其他组不发写入。范围外的像素漂移不阻断本组；一个组的冲突不阻断其它组。报告标明发布与面板身份，组按稳定 `group_id`、证据按块坐标可复现排序；报告原子新建，不覆盖旧文件。合法回读中的冲突、缺读或无须写入是正常结果（退出 0）；坏输入、找不到匹配发布、摘要冲突或文件错误退出 2，且不产生新的成功报告、不破坏既有结果。
