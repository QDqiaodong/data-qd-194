# 离线素材编译器与取帧 v3

在保留 v1 排版、v2 `seal`/`reconcile` 契约的前提下，新增两个离线子命令；不接设备、不处理在线换版。

```
pixel-type compile-pack --source SOURCE --output PACK
pixel-type unpack-frame --pack PACK --scene ID --output FRAME
```

## 输入

`compile-pack` 的源 JSON 字段：`width`、`height`、`payload_budget`、`scenes`。

- `width`、`height` 为 8 的正整数倍，最大 256×128。
- `payload_budget` 为 0..524288 的整数字节数，只计 Base64 解码后的载荷字节。
- `scenes` 为 1..16 项，每项 `id`、`direct_only`、`layout`：
  - `id` 唯一，1..64 个 ASCII 字母、数字、下划线或连字符；
  - `direct_only` 为布尔值；
  - `layout` 是完整 v1 排版输入，按现有字符顺序、字偶间距、自动换行、字形偏移渲染。

每屏的实际亮点取渲染像素并集：同一坐标只亮一次，空 `rows` 空白字形不点灯。任何实际亮点越出物理屏使整包失败，不裁切；仅名义排版溢出而实际亮点仍在屏内则不失败。

## 终端读取契约

整屏按块行从上到下、同一行从左到右给 8×8 块从 0 编号（`block = ty * tile_cols + tx`）。每块 8 字节，自上而下每像素行一字节，最左像素占最高位。

- **整帧**（`full`）：顺序存下屏上所有块，含全暗块，长度恒为 `块数 × 8`。
- **引用帧**（`reference`）：首字节是基础场景的零基目录序号；随后 2 字节无符号小端为改动块数；再按块编号递增写改动项，每项 2 字节无符号小端块编号 + 8 字节逐位异或掩码。只写掩码非零的块，允许零项。长度恒为 `3 + 10 × 改动块数`。

基础场景必须是本包另一张整帧，不能引用引用帧，也不能依赖屏内残留像素；引用帧与基础的目录先后无关。`direct_only=true` 的场景必须用整帧（冷启动只认整帧），仍可作为其他场景的基础。

## 最优分配

在所有合法整帧/引用帧分配中取载荷最小者：任何 `direct_only` 场景强制整帧，其余场景可以是整帧或引用任一整帧基础。分配按全局枚举求解，不采用"每场景各挑最相似图"的贪心，也允许链式关系不成立（引用只能指向整帧）、也不强迫全整帧；相距甚远的场景可能整帧更省。

等长时先按目录顺序比较各记录格式（整帧排在引用帧前），再按目录顺序比较各引用帧的基础序号，取字典序最小。目录按 ASCII 场景 ID 排序，序号据此确定；载荷按目录顺序无缝拼接。打乱 `scenes` 顺序不改变成功包的文件字节。

最小合法载荷超过 `payload_budget` 时退出 2，在 stderr 报出最小所需字节数与给定预算，不产出部分包。

## 包结构

自包含 JSON，至少含：

- `schema_version`：格式版本，当前为 1；
- `kind`：`pixel-type.pack`；
- `width`、`height`、`tile_cols`、`tile_rows`；
- `payload_budget`、`payload_bytes`：后者为 Base64 解码后载荷的实际字节数；
- `payload_base64`：按目录顺序无缝拼接的载荷；
- `catalog`：按 ASCII ID 排序的场景数组，每项含 `id`、`direct_only`、`format`（`full`/`reference`）、`offset`、`length`。

## 取帧

`unpack-frame` 只用包本身重建任一场景，原始布局文件可以不存在。输出 JSON 含 `schema_version`、`kind`、`id`、`width`、`height` 及完整 `tiles`；每块为 `tx,ty,rows`，按块编号顺序，每行 8 个 `01` 字符，含全暗块。

取帧前校验整包结构，任一坏记录（即使未被选中）都使整包失败：

- 非法版本、尺寸或非 8 倍数；
- 目录为空、非 ASCII ID 递增顺序、重复 ID、未知格式；
- 记录边界：offset 不连续（空洞/重叠）、长度不符、载荷尾部多余字节；
- `payload_bytes` 与解码后长度不符、非法 Base64；
- 引用帧基础序号越界、改动块越界或无序/重复、全零掩码；
- `direct_only` 帧被编码为引用帧；
- 引用帧指向引用帧（引用链）。

不要求重新计算第三方包的最优性。非法输入、未知场景与文件错误退出 2；两个命令都只原子新建成功输出，不覆盖已有文件。合法包中可能出现的其它分配仍可正常取帧。
